# 飞书招聘候选人采集器（增强版）

一个 Tampermonkey（油猴）用户脚本，在飞书招聘候选人列表页面自动显示采集按钮，一键抓取候选人信息并导出为 JSON / CSV，可配合飞书内部 AI（豆包 / iDA / Aime）自动填写台账。

将手动录入 100 名候选人的时间从约 30 分钟缩短至 1-2 分钟。

## 功能

- 一键采集候选人列表，自动滚动加载全部数据
- 字段自选：表头设置里勾选哪些列就采哪些列
- 联系方式自动补全：调用接口获取手机号 / 邮箱，支持并发控制、失败重试、限流退避
- 评估结论自动获取：按接口拉取面试评估结论
- 导出 JSON / CSV，CSV 可直接用 Excel 打开
- 复制邮箱（去重、分号分隔），方便粘贴到飞书邮箱密送群发
- 登台账：自动生成含 JSON 数据和填写规则的 AI 提示词，发给豆包 / iDA / Aime 即可自动写入台账
- 断点续抓：意外中断后可继续，30 分钟内有效
- 失败重试：单独重试联系方式 / 评估结论获取失败的记录
- 结果筛选与搜索：按姓名 / 学校 / 岗位搜索，快捷筛选有联系方式 / 仅失败项
- 悬浮按钮可拖拽、位置记忆，双击空白处复位
- 数据仅存在浏览器内存中，关闭页面或"关闭并清空"后即清除

## 安装

### 1. 安装油猴插件

打开 Chrome 网上应用店，安装 [Tampermonkey](https://chrome.google.com/webstore/detail/tampermonkey/dhdgffkkebhmkfjojejmpbldmpobfkfo)。

> **Chrome 用户请注意**：安装后需进入 `chrome://extensions/`，找到 Tampermonkey，确保开关已启用。如果 Chrome 弹出"此扩展程序将能够运行未经 Google 审核的代码"的提示，点击"允许"即可——这是用户脚本管理器的正常权限提示。

### 2. 一键安装脚本

点击下方链接，油猴会自动弹出安装页面，点「安装」即可：

[👉 点此一键安装脚本](https://raw.githubusercontent.com/pingwenchao/hire-candidate-grabber/main/hire-candidate-grabber.user.js)

### 3. 确认启用

点击浏览器右上角油猴图标 →「管理面板」，确认「飞书招聘候选人采集器（增强版）」状态为已启用（开关为绿色）。

## 使用

1. 进入飞书招聘系统的候选人列表页，先在表头设置中勾选需要的字段。
2. 页面右下角出现「📋 采集候选人」和「⚙️」按钮，点击「采集候选人」。
3. 在弹出的列选择面板中勾选要抓取的列，点「开始抓取」。
4. 抓取过程中顶部显示实时进度，可随时取消。
5. 完成后弹出结果面板，可复制 JSON、导出 CSV、复制邮箱、登台账、重试失败项。

## 高级设置

点击右下角 ⚙️ 齿轮按钮可调整：

| 设置项 | 说明 | 默认值 |
|-|-|-|
| 去重模式 | 按候选人或按申请去重 | 按候选人 |
| 联系方式并发数 | 同时请求数量（1-10） | 6 |
| 联系方式请求间隔 | 每次请求间隔（ms） | 120 |
| 每次滚动距离 | 滚动加载步长（px） | 600 |
| 滚动后等待 | 等待页面加载时间（ms） | 350 |
| 面板中脱敏显示 | 结果面板默认打码 | 开启 |
| 导出/复制时也脱敏 | 复制出去的数据也打码 | 关闭 |
| 常用台账链接 | 预设后登台账不用每次填写 | 空 |
| 字段映射 | JSON 格式，将抓取字段名改为台账字段名 | 空 |

## 注意事项

- 脚本仅在本人有权限访问的飞书招聘页面运行，只采集当前任务必需的字段
- 候选人姓名、电话、邮箱等属于个人敏感信息，禁止发送到外部服务或外部群聊，禁止保存到个人设备或非授权空间
- 数据仅存在当前浏览器内存中，使用后请及时点击「关闭并清空」或关闭页面
- 请勿随意调大并发数或缩短请求间隔，避免对系统服务造成压力
- 脚本不得用于绕过权限、验证码或系统安全控制
